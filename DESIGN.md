# VYAN Netra Design Brief

## Overview
Cosmic AI void admin command center for VYAN Labs ecosystem. Immersive, futuristic space-age interface with animated nano-particle effects and glass morphism surfaces.

## Visual Direction
**Tone**: Bold, high-tech, immersive, premium futuristic | **Differentiation**: Living nano-particle orb system in primordial core hero section; unified command interface across 8 product domains.

## Typography
**Display Font**: Space Grotesk (geometric, tech-forward, futuristic) | **Body Font**: General Sans (refined, readable, modern) | **Monospace**: Geist Mono (dashboard metrics, code areas)

## Elevation & Depth
Glass morphism with frosted effect (12px backdrop blur). Layered surfaces: void background → semi-transparent cards (10-15% opacity) → elevated interactive elements (glow accents). Subtle depth shadows only on interactive zones.

## Structural Zones
| Zone | Treatment | Purpose |
|------|-----------|----------|
| Hero (top-center) | Animated particle system + primordial core nucleus | Command center focal point, system vitality |
| Header | Flat, cosmic silver text on void | VYAN Netra branding, time/status readout |
| Sidebar Nav | Glass cards with 12% opacity, accent highlights | Product access (Products, Users, Monitoring, Notifications, Issues, Updates, Email, Settings) |
| Main Content | Grid of glass morphism cards | Feature panels, admin controls, metric displays |
| Footer | Minimal, cosmic silver text | Status indicators, system health |

## Spacing & Rhythm
Dense card grid (16px-24px gaps). Tight vertical rhythm (1.4-1.6x line-height). Icon-driven UI with sparse labeling. High information density balanced by glass transparency.

## Component Patterns
- **Buttons**: Glass background with cosmic silver text, glow-on-hover. No hard borders.
- **Cards**: Frosted glass (backdrop-filter blur 12px), 1px subtle border, minimal corner radius (0-4px).
- **Input**: Inline text on void, subtle border-bottom underline, focus = glow accent.
- **Navigation**: Vertical sidebar, cosmic accents on active item, float animation on hover.

## Motion & Animation
**Particle System**: Nano-orbs drift, rotate, pulse around primordial core (continuous, subtle, organic). **UI Motion**: Smooth transitions (0.3s cubic-bezier 0.4 0 0.2 1). Float animation on cards (±8px translateY, 4s cycle). Pulse-glow on active elements (3s). Particle-drift on floating action buttons (6s).

## Constraints
- No flat bright colors; all tokens exist in cool blue-violet-silver spectrum.
- All card shadows use glow effect, never hard drop-shadow.
- Animations are subtle and continuous; no jarring easing.
- Text contrast maintained at WCAG AA+ on void black background.
- Glass effect opacity locked to 10-15% for legibility over animated backdrop.

## Signature Detail
Nano-particle primordial core in hero — a living, breathing representation of the central command nexus. Particles orbit, emit glow, respond to system state. The core is the visual anchor that sets VYAN Netra apart from generic dashboards.
